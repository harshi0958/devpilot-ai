# DevPilot AI Branding Assets

This folder contains all official branding assets for DevPilot AI.

## Files

- logo.svg — Primary horizontal logo
- logo-horizontal.svg — Alternative horizontal layout
- logo-icon.svg — DP Monogram
- favicon.svg — Browser favicon
- app-icon.svg — Application icon
- splash-logo.svg — Splash screen logo
- loading-logo.svg — Loading animation logo

## Rules

- Do not modify colors.
- Do not stretch the logo.
- Do not rotate the logo.
- Use SVG whenever possible.
- Use logo-icon.svg for favicon and app icons.
